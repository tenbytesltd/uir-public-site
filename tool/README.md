# Public UIR showcase verifier

This directory is intentionally small and public. It proves the website's
reproducible boundary without copying or requiring access to the private alpha
UIR core repository.

`public_site_ci.py` independently verifies that:

- `uir/author_site.py` reproduces every committed model shard;
- the package manifest lists the exact shard set and hashes;
- the package is unchanged from the maintainer-reviewed official audit;
- unchecked gates and compiler deferrals still match the explicit baseline.

The official semantic audit is generated by the pinned UIR maintainer workflow
and committed as evidence. The public verifier does not claim to rerun that
private alpha compiler. This split lets forks and pull requests verify every
public claim without Tenbytes credentials while keeping the trust boundary
visible.
